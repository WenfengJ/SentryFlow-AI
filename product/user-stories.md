# 用户故事 / User Stories

## 场站业主 / Site Owner

作为远程太阳能场站业主，我希望在有人夜间进入禁区时收到清晰的风险解释，从而判断是否通知安保或忽略误报。  
As a remote solar site owner, I want to receive a clear risk explanation when someone enters a restricted area at night, so that I can decide whether to notify security or ignore a false alarm.

## 运维经理 / Operations Manager

作为运维经理，我希望每天收到巡检摘要，从而不用手动查看数小时摄像头画面。  
As an operations manager, I want a daily inspection summary, so that I do not need to watch hours of camera footage manually.

## 安防服务商 / Security Vendor

作为安防服务商，我希望把摄像头硬件和 AI 巡检报告打包成方案，从而向工业客户提供更高价值的服务。  
As a security service provider, I want to package camera hardware with AI inspection reports, so that I can offer a higher-value service to industrial clients.

## 现场技术员 / Field Technician

作为现场技术员，我希望未解决事项被清晰列出，从而知道下次到场时优先检查什么。  
As a field technician, I want unresolved issues to be listed clearly, so that I know what to check during the next site visit.

## eufy / Anker 业务团队 / eufy / Anker Business Team

作为硬件生态团队，我希望找到 eufy 摄像头进入工业和小商业场景的实用扩展方向，从而让设备从消费级监控延伸到工业边缘场景。  
As a hardware ecosystem team, I want a practical industrial extension scenario for eufy cameras, so that the device can move from consumer monitoring into small business and industrial edge use cases.
