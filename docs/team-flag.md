# 团队旗帜

## 团队名称

SentryFlow AI 巡检小队

## 组队需求描述

我想做一个 Anker / eufy 黑客松项目：**SentryFlow AI**。

方向是把 eufy 摄像头从家庭看护，延展到远程能源与工业场站，让摄像头不只是“运动提醒”，而是能理解画面、解释风险、推动处理的 AI 巡检员。

MVP 先聚焦三个场景：

1. 夜间入侵：有人进入围栏或设备区，系统识别风险并给出处置建议
2. 设备区异常：遮挡、低光、烟雾 / 火光、异常停留等风险标记
3. 自动巡检报告：每天汇总事件次数、风险等级、设备状态和待处理事项

这个方向和很多家居、宠物、门口看护类项目不太一样。它更偏太阳能 / 储能场站、工业园区、矿区、远程工地、仓库等场景。这里的痛点比较明确：场站分散、人工巡检贵、夜间风险高，传统 CCTV 只能录像，不能解释风险，也不能把事件沉淀成巡检报告。

我本人有 10 年 IT 经验，可以承担全栈和大数据实时处理，熟悉日志采集、事件处理、过滤、监控、告警等链路，也可以一起做市场调研、竞品分析和产品表达。

现在想找 2-3 位队友，最好能补这些方向：

- 多模态 / CV：图片或视频风险识别
- 前端 / 产品：Dashboard、事件工作台、巡检报告
- IoT / 后端：摄像头事件流、eufy SDK 接入、数据接口
- 调研 / Pitch：市场调研、竞品分析、商业化表达

虽然是我先发起这个组队想法，但技术和产品方向都希望大家一起共创、互相学习。队伍不预设固定队长，哪个方向谁更擅长，就由谁来主导。

如果你也想做一个“硬件 + AI + 真实场景 + 有机会商业化”的项目，可以一起聊聊。
