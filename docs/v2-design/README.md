# v2 黑客松参赛设计

SentryFlow AI v2 是本次参赛主线：

```text
SentryFlow AI：面向小商业、仓库、轻工业和远程边缘资产的 eufy AI 安防交接服务。
```

v2 从 v1 的“远程能源/工业场站 AI 巡检 Agent”收敛而来，主线更贴近 Anker / eufy 智能安防赛道，也更适合 24 小时 Demo 和现场路演。
