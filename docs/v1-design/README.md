# v1 原始产品方向

v1 是 SentryFlow AI 的早期产品方向，核心设想是：

```text
让 eufy 摄像头成为远程太阳能、储能和工业场站的 AI 巡检员。
```

这个方向强调远程能源场站、工业园区、仓库、矿区和远程工地等场景，通过摄像头事件、AI 风险解释、处置建议和每日巡检报告，降低人工巡检成本。

## 当前定位

v1 不建议作为本次 Anker / eufy 黑客松的主叙事。

原因：

- 场景偏 B2B 和工业平台，评委理解成本更高。
- 与 eufy 当前家庭、小商业、户外轻量安防心智距离更远。
- 24 小时 Demo 容易做成大平台展示，不如 v2 的交接闭环直接。
- 能源/工业方向有价值，但更适合放在未来扩展或高价值样例里。

## 如何使用 v1

v1 可以作为三类素材保留：

1. 长期愿景：说明 SentryFlow AI 未来可以从小商业扩展到远程能源和工业资产。
2. Demo 扩展：作为 v2 里的第二个高价值样例，例如“暴雨后的太阳能小站”。
3. 技术素材：复用事件分析、巡检报告、设备区异常、风险解释等设计。

## 和 v2 的关系

v1 的价值不是被废弃，而是被降级：

```text
v2 是本次参赛主线；
v1 是未来扩展和背景素材。
```

参赛路演中可以这样保留 v1：

```text
我们先从小商业和仓库的 eufy Morning Handoff 切入。
未来同一套事件复核和交接能力，可以扩展到小型太阳能/储能站、农场、轻工业园区等远程边缘资产。
```
