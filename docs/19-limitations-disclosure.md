# 19 Limitations Disclosure

这份文档用于答辩备用材料。SentryFlow AI 当前 Demo 展示的是产品闭环和可落地架构，不夸大真实接入范围，也不把 AI 输出包装成最终安防裁决。

## 1. 当前不承诺已接入官方 eufy SDK

当前 Demo 不声明已经接入官方 eufy SDK。

准确表述：

```text
当前 Demo 使用模拟 eufy 摄像头事件流。系统架构预留了 eufy SDK adapter，如果官方提供稳定 SDK/API、设备和权限，可以把事件来源替换为真实 eufy 事件。
```

不能说：

```text
我们已经接入官方 eufy SDK。
```

原因：

- 当前无法确认比赛现场是否提供官方设备、账号、SDK/API 权限。
- 黑客松 Demo 的核心验证点是交接流程、AI 复核、风险排序和处置闭环。
- 真实 SDK 只属于事件来源层，不应该影响后续 Event Schema、AI Review、Risk Engine 和 Handoff Summary。

## 2. 当前 Demo 可使用模拟事件流

当前 Demo 可以使用模拟事件流完成完整演示。

准确表述：

```text
模拟事件流用于保证现场演示稳定。它不是产品能力造假，而是把真实摄像头告警抽象成统一 Event Schema，先验证后续 AI 复核和交接闭环。
```

模拟事件包含：

- 47 条夜间运动告警。
- 44 条 ignored。
- 2 条 explained。
- 1 条 action_needed。
- 后门 02:13 陌生人停留事件。

数据位置：

- `app/data/events.json`
- `app/data/reviewed_events.json`
- `app/data/handoff_summary.json`
- `app/data/actions.json`

## 3. 当前不做生产级实时视频流

当前版本不做生产级实时视频流处理。

准确表述：

```text
当前 Demo 处理的是事件级数据：截图、短视频片段、时间、摄像头位置、营业状态和设备状态。它不是实时视频监控平台，也不是完整 NVR。
```

当前包含：

- 运动事件复核。
- 事件截图或短视频占位。
- 夜间事件汇总。
- 风险解释和建议动作。

当前不包含：

- 实时多路视频流。
- 生产级视频存储。
- 摄像头实时调度。
- 大型 CCTV 指挥中心能力。

## 4. 当前不替代安保责任人

SentryFlow AI 不替代店主、仓库管理员、安保人员或企业责任人。

准确表述：

```text
AI 的角色是复核、解释和交接，帮助用户减少无效告警，并把真正需要处理的事件交给人。最终判断和处置仍由人完成。
```

不能说：

```text
AI 可以自动判断所有安全事件并完成处置。
```

产品边界：

- AI 可以指出风险原因。
- AI 可以建议下一步动作。
- AI 可以提醒人工复核。
- AI 不承担最终安全责任。
- AI 不替用户报警、定责或确认入侵。

## 5. AI 不做最终安全裁决

AI 输出不能被描述为最终裁决。

准确表述：

```text
AI 会把事件分为 ignored、explained、action_needed 或 review。高风险或不确定事件必须进入人工复核。
```

AI 可以输出：

- 事件摘要。
- 风险等级。
- 误报可能。
- 证据点。
- 风险原因。
- 建议动作。
- 是否需要人工复核。

AI 不输出：

- `一定入侵`
- `一定安全`
- `已经确认犯罪`
- `不需要人再看`
- `自动完成安防处置`

## 6. 高风险或不确定事件必须人工复核

当前规则：

```text
高风险事件 -> action_needed -> 人工复核
不确定事件 -> review -> 人工复核
低价值噪声 -> ignored
可解释事件 -> explained
```

后门 02:13 事件的口径：

```text
这是一个需要优先处理的高风险事件，因为它发生在营业外时间、后门敏感区域，并且人员停留超过 30 秒。系统建议开门前检查后门门锁，并请店长复核画面。
```

不能说：

```text
这个人一定是入侵者。
```

## 7. 答辩备用口径

如果评委问：你们现在到底做出来了什么？

回答：

```text
我们做出了一个可执行 Demo：用 47 条模拟 eufy 摄像头夜间告警，跑通事件复核、误报降噪、风险排序、晨间交接、AI 问答和处置状态。当前不承诺已接入官方 eufy SDK，但架构上预留了 SDK adapter，真实事件和模拟事件会进入同一套 Event Schema。
```

如果评委问：这是不是只是模拟数据？

回答：

```text
现场 Demo 使用模拟事件流保证稳定，但模拟的是 eufy 摄像头已有的运动告警、截图/片段、摄像头位置、设备状态和营业上下文。我们验证的是告警之后的 AI 交接闭环。SDK 可用时，替换事件来源即可。
```

如果评委问：AI 判断错了怎么办？

回答：

```text
我们不让 AI 做最终安全裁决。高风险和不确定事件都必须人工复核。AI 给出证据点、风险原因和建议动作，帮助用户决定先看哪里、通知谁、如何关闭交接。
```
